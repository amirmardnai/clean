# به‌روزرسانی: پاکسازی ساختارمحور برای هر متن ثبت‌شده روی صفحه

این نسخه مشکل «پاک نشدن تیترها و متن‌های روی تصویر» را رفع می‌کند. از این پس
`translate_manhwa_pro.py` (همان چیزی که `run_translate_all.bat` اجرا می‌کند)
برای هر متن تشخیص‌داده‌شده به‌طور خودکار یکی از دو مسیر را انتخاب می‌کند:

| نوع ناحیه | مسیر | نتیجه |
|---|---|---|
| حباب سفید / ناحیه تخت روشن | مسیر قبلی (inpaint + متن ساده فارسی) | دقیقاً همان رفتاری که قبلاً کار می‌کرد |
| متن روی تصویر / بافت / پنل تیره | `scripts/clean_lettering.py` (پاکسازی ساختارمحور خود‑تأییدکننده) + بازتایپ با **رنگ و استروک نمونه‌گیری‌شده از خود متن اصلی** | بدون کادر سفید/خاکستری؛ تلفیق با تصویر |

## چه چیزهایی تغییر کرده

- `scripts/clean_lettering.py` — بازنویسی کامل پاکسازی: تشخیص چهار نوع زمینه
  (تخت/خط‌دانه‌دانه/هفتن‌تون دوره‌ای/لوزی لبه‌دار)، چند کاندیدای پرشدن +
  امتیازدهی کمی در مقایسه با زمینه اطراف، پرهیز از تکثیر زنجیره‌ای کپی
  (رفتن با گام دوره به پیکسل‌های تمیز واقعی)، تصحیح سینتیک‌گریدیانت، و
  پاس «متن باقی‌مانده» تا سایه‌های جزئی هم پاک شوند.
- `translate_manhwa_pro.py` — مسیردهی خودکار (جدول بالا)، نمونه‌گیری رنگ و
  استروک واقعی حروف با انتخاب خوشه k-means و قواعد خوانایی؛ صفحه به‌صورت
  RGBA پیش می‌رود تا نوشتن روی artwork با محتوای واقعی آلفا شود.
- `run_translate_all.bat` — فقط مستند شد؛ رفتاری عوض نشده.
- `README.md` / `SKILL.md` — توضیح ورژن جدید.

## اجرا

همان قبلی است: `run_translate_all.bat` را دوبار کلیک کنید. چند سوییچ اختیاری
جدید (در خود فایل bat کامنت‌گذاری شده‌اند):

```
--langs en,ko     خواندن کره‌ای هم (علاوه بر انگلیسی)
--cpu             اگر GPU در دسترس نیست
--slant 0         نوشتار بدون کجی (پیش‌فرض ۰٫۱۲ کج خفیف مانند متن اصلی)
--no-artwork      بازگشت به رفتار قدیمی (کادر تخت)
--debug-boxes     قاب آبی=artwork / قرمز=حباب برای اشکال‌زدایی سریع
```

کلید API را می‌توان بدون ویرایش فایل از طریق متغیر محیطی `MANHWA_API_KEY`
داد (ترجیح داده می‌شود)؛ سرویس LLM هم با `MANHWA_LLM_URL` و
`MANHWA_LLM_MODEL` قابل تغییر است.

## تست شده روی چه چیزهایی

1. تیتر «BELT OF THE FOUR / GREAT POWERS» روی آرمور قرمز (نمونه ارسالی شما)
2. دو متن جدا «DIE HERE» و «NOW!!» روی خط‌های سرعتی
3. صفحه واقعی PDF تستی (سیمبل روی زمینه ناهموار + حباب‌های عادی): هر دو
   مسیر با هم در یک صفحه
4. پنل سیستم آبی یکدست
5. به‌علاوه پنج سناریوی زمینه متفاوت در تست واحد پاکسازی
   (سن الگریدیانت سین، بافت هفتن‌تون، خط‌های فیبری، آسمان، آرمور)

نتایج تصویری در `docs/verification/SUMMARY_FA.png`.

> نکته: اگر صفحه‌ای قبلاً با نسخه قدیمی ترجمه و در شاخه کاری ذخیره شده باشد،
> فایل خروجی آن صفحه (در `_work_pro/…/out/`) را پاک کنید تا با مسیر جدید
> دوباره پردازش شود؛ پایپ‌لاین برای صفحات تمام‌شده «اسکیپ» دارد.
